## Запуск на ПК

### Python: работа №3

Открыть [Lab3_OOP/lab3.py](Lab3_OOP/lab3.py) в IDLE и нажать F5, либо выполнить из общей папки:

```text
python Lab3_OOP/lab3.py
```

Используются только стандартные возможности Python 3; установка дополнительных пакетов не требуется.

### HTML и JavaScript: работы №4–6

Открыть нужный файл в Google Chrome или Microsoft Edge:

- [Lab4/index.html](Lab4/index.html)
- [Lab5/index.html](Lab5/index.html)
- [Lab6_DOM/index.html](Lab6_DOM/index.html)

В Windows: правая кнопка на `index.html` → «Открыть с помощью» → браузер. Файлы `style.css` и `script.js` должны оставаться в той же папке. Страницы работают локально без сервера, интернета, фреймворков и внешних библиотек.

## Дополнительные функции

- №3: цвет прямоугольника, место измерения температуры, название библиотеки и подсчёт книг.
- №4: счётчики символов, подсветка ошибок и очистка форм.
- №5: подсветка чётных произведений, счётчики найденных студентов и товаров, сброс фильтров.
- №6: счётчик приветствий, запрет повторных тегов, выбор размера объекта и повторный запуск игры.

Имена студентов, товары и цены в работе №5 являются учебными примерами. Минимальная длина мотивации в работе №4 выбрана равной 100 символам; цель игры в работе №6 — 10 попаданий. Эти значения не уточнялись в исходных условиях и отмечены в отчётах как решения реализации.
